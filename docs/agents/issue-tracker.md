# GitHub issues

Use `ovsw/maplewoodyearround.com-2026`. Issue #1 is the spec;
issues #2 through #19 define the work.

Read the body, labels and comments before claiming an issue. Check every
"Blocked by" issue is closed. Claim the lowest eligible number with
`gh issue edit N --add-assignee @me`, then comment "taking this".
Follow the worktree, PR, merge and reporting rules in `AGENTS.md`.

Keep private people, account details and credentials in the Basecamp document
named in the spec. Public comments describe blockers without private values.
Use `ready-for-human` when only Ovi can resolve a blocker.
