# Triage labels

- `ready-for-agent`: an agent can take the issue once its blockers are closed.
- `ready-for-human`: an action or decision requires Ovi.
- `needs-info`: facts are missing to define or reproduce the work.
- `needs-triage`: the issue needs classification.
- `wontfix`: the work will not be done.

A label does not permit bypassing dependencies.
Comment with the exact missing action when marking a human blocker.
